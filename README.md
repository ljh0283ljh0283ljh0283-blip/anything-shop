# 무엇이든 상점

물건부터 미소까지 무엇이든 파는 작은 쇼핑몰 웹사이트입니다.

- `index.html` 페이지
- `style.css` 디자인
- `app.js` 장바구니, 분류 필터
- `products.json` 처음 상품 목록. 관리자가 처음 들어오면 구글 시트 "운영 상품" 탭으로 옮겨지고, 그 뒤로는 시트가 기준입니다
- `settings.json` 주문 받을 주소(orderUrl), 판매자별 입금 계좌(sellers: 판매자 이름 → 계좌), 판매자를 비워 둔 상품(운영자 직접 판매)의 계좌(bank)
- `terms/` 이용약관 페이지
- `seller.js` "판매자 되기" 신청서. 신청하면 바로 판매자 열쇠가 나오고, 바닥글 "판매자 로그인"에서 그 열쇠로 들어가 자기 상품을 올림. 판매자와 판매자 상품은 `orderUrl` 구글 시트의 "판매자 신청", "판매자 상품" 탭에 저장되고, "게시" 상태인 상품이 바로 상점에 보임
- 상품에 `"sample": true`를 넣으면 "샘플" 칸에만 보이고 주문·제안을 받지 않음
- `order-script.gs` 주문을 구글 시트에 쌓는 스크립트 (구글 시트 > 확장 프로그램 > Apps Script에 붙여 넣고 웹 앱으로 배포)
- 사이트 관리자: 바닥글 "사이트 관리자"에서 관리자 비밀번호로 들어옵니다. 비밀번호는 Apps Script 프로젝트 설정 > 스크립트 속성 `ADMIN_KEY`에 적어 둡니다

## 어떻게든 팔거야 (`offer/`)

가격을 판매자가 정하지 않고 손님이 제안하는 상점입니다. 주소: `/anything-shop/offer/`

1. 판매자는 가격 없이 상품 설명만 올립니다. (`offer/products.json`, 사이트 아래쪽 **판매자 > 상품 관리**에서 GitHub 열쇠로 등록)
2. 손님은 상품마다 한 개당 가격과 수량을 제안합니다. 여러 사람이 제안할 수 있고, 카드에 제안 수와 최고 제안가가 보입니다.
3. 판매자는 **판매자 > 받은 제안**에서 제안을 보고 **팔기**(수락) 또는 **안 팔기**(거절)를 누릅니다. 손님은 **내 제안**에서 결과와 입금 계좌를 확인합니다.

- `offer/settings.json` 제안 받을 주소(offerUrl), 입금 계좌, 오픈 여부(open)
- `offer/offer-script.gs` 제안을 구글 시트에 쌓고 수락/거절을 기록하는 스크립트

연결 순서:

1. 새 구글 시트를 만들고 확장 프로그램 > Apps Script에 `offer/offer-script.gs`를 붙여 넣습니다.
2. 프로젝트 설정 > 스크립트 속성에 `ADMIN_KEY`를 추가하고 나만 아는 글자를 넣습니다. (판매자 열쇠)
3. 배포 > 새 배포 > 웹 앱, 액세스 권한 "모든 사용자"로 배포하고 나온 주소를 `offer/settings.json`의 `offerUrl`에 넣습니다.
4. 준비가 되면 `open`을 `true`로 바꿉니다.
