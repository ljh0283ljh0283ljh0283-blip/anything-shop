# SEKI POmall 회사 서버

구글(Apps Script + 구글 시트 + 드라이브)이 하던 일을 회사 컴퓨터 한 대가 하도록 만든 프로그램입니다.
발주, 거래처, 상태 기록, 첨부 발주서를 모두 회사 컴퓨터 안의 `data` 폴더에 저장합니다.
주문 화면(사이트)도 이 서버가 함께 보여 줄 수 있습니다.

## 1. 준비물

- 늘 켜 두는 회사 컴퓨터나 서버 한 대 (윈도우, 맥, 리눅스, NAS 모두 됩니다)
- **Node.js 22.13 이상**: https://nodejs.org 에서 "LTS"를 내려받아 설치합니다.
  설치 후 명령창에서 `node -v` 를 쳐서 `v22.13` 이상이 나오면 됩니다.
- 이 저장소의 `pomall-server` 폴더와 `pomall` 폴더 (둘이 나란히 있어야 합니다)

다른 프로그램은 따로 설치할 필요가 없습니다.

## 2. 열쇠 정하기

1. `config.example.json` 을 복사해서 이름을 `config.json` 으로 바꿉니다.
2. `config.json` 을 메모장으로 열고 세 열쇠를 적습니다.
   - `adminKey`: 관리자 열쇠 (8글자 이상이어야 서버가 켜집니다)
   - `salesKey`: 영업팀 열쇠
   - `viewKey`: 조회 전용 열쇠
3. 지금 쓰는 열쇠를 그대로 써도 되고 새로 정해도 됩니다.

`config.json` 은 저장소에 올라가지 않게 막아 두었습니다. 열쇠는 이 파일에만 적고, 메신저나 이메일로 보내지 마세요.

나머지 칸의 뜻:

| 칸 | 뜻 |
|---|---|
| `port` | 서버가 쓰는 번호 (기본 8080) |
| `dataDir` | 자료를 저장할 폴더 |
| `publicUrl` | 바깥에서 들어오는 주소 (예: `https://pomall.회사.co.kr`) |
| `allowOrigin` | 다른 주소의 사이트가 이 서버를 쓰게 할지. 모르면 `*` 그대로 |

## 3. 서버 켜기

명령창에서 `pomall-server` 폴더로 들어가 다음을 칩니다.

```
npm start
```

`SEKI POmall 서버가 켜졌어요` 가 나오면 성공입니다.
같은 컴퓨터의 인터넷 창에서 `http://localhost:8080` 을 열면 주문 화면이 보입니다.

## 4. 구글에 있는 자료 옮기기 (한 번만)

1. 저장소의 최신 `pomall/pomall-script.gs` 를 Apps Script(SEKI POmall)에 붙여 넣고
   **배포 관리 > 연필 > 새 버전 > 배포** 를 합니다. (자료를 내보내는 기능이 이 버전에 들어 있습니다.)
2. 서버를 잠깐 끈 상태(명령창에서 Ctrl+C)로 다음을 칩니다.

```
npm run import -- --url "Apps Script 주소" --key "관리자 열쇠" --save export.json
```

3. `옮기기 끝: 발주 ○건, 거래처 ○곳 …` 이 나오면 끝입니다. `export.json` 은 구글 자료의 백업본이니 안전한 곳에 보관하세요.
4. 다시 `npm start` 로 켭니다.

- 거래처는 쓰던 비밀번호 그대로 로그인합니다.
- 지난 발주서 첨부 파일은 구글 드라이브 링크를 그대로 씁니다. 새로 올리는 발주서부터 회사 서버에 저장됩니다.
- 이미 자료가 있는 서버에 다시 옮기려면 끝에 `--force` 를 붙입니다. (서버의 기존 발주·거래처·상태 기록을 지우고 새로 옮깁니다.)

## 5. 바깥에서 들어오게 하기

거래처가 회사 밖에서 주문하려면 다음이 필요합니다. 회사 IT 담당자나 업체에 맡기면 됩니다.

1. 회사 주소(도메인)를 하나 정합니다. 예: `pomall.회사.co.kr`
2. **HTTPS(자물쇠 표시)** 를 붙입니다. Nginx, Caddy, NAS의 "역방향 프록시" 기능 등으로 8080 번을 연결합니다.
   비밀번호가 오가므로 HTTPS 없이 바깥에 열면 안 됩니다.
3. `config.json` 의 `publicUrl` 에 그 주소를 적고 서버를 다시 켭니다.

이제 거래처는 `https://pomall.회사.co.kr` 로 들어와 주문합니다.
(지금의 GitHub 주소를 계속 쓰고 싶다면 `pomall/settings.json` 의 `orderUrl` 을 `https://pomall.회사.co.kr/api` 로 바꾸면 됩니다.)

## 6. 늘 켜 두기와 백업

- 컴퓨터를 켤 때 서버도 저절로 켜지게 합니다. (윈도우: 작업 스케줄러, 리눅스: systemd 또는 pm2, NAS: 작업 예약)
- **`data` 폴더가 모든 자료입니다.** 매일 다른 디스크나 클라우드에 복사해 두세요.
  - `data/pomall.db`: 발주, 거래처, 상태 기록, 설정
  - `data/files/`: 거래처가 올린 발주서

## 바뀌지 않는 것

- 주문 화면, 관리 화면, 열쇠, 상태 규칙, 발주번호 모양은 구글 때와 똑같습니다.
- 사양 코드와 가격은 `pomall/products.json` 을 그대로 읽습니다.
