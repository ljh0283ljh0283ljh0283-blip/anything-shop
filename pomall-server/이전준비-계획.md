## 실제로 옮기는 날의 순서 (요약)

자세한 설명은 [README.md](README.md) (설치 설명서)에 있습니다.

1. 회사 윈도우 PC에 Node.js 설치
2. 설치 파일 묶음을 `C:\POmall` 에 풀고 `pomall-server\windows\1-setup.bat` 실행 (열쇠, 메일 설정 입력)
3. 구글 Apps Script에 데이터 내보내기 기능이 있는 최신 스크립트를 배포
4. `2-import.bat` 실행: 구글 시트 데이터를 서버로 옮김
5. `3-start.bat`로 켜서 회사 안에서 접속 시험
6. 도메인 연결(HTTPS) 후 밖에서 접속 시험
7. `4-autostart-on.bat`: PC 켜면 자동 시작 + 매일 백업
8. 거래처에 새 주소 안내, 구글 쪽은 일정 기간 읽기 전용으로 남겨 둠

## 시험한 것 (2026-11-18)

- 로그인과 6시간 입장권, 견적 모델 주문, 5번 틀리면 잠금, 메일 인증번호로 비밀번호 바꾸기, 찾기 요청, 관리 열쇠 잠금, 내보내기 → 다른 PC로 옮기기
- 실제 화면(견적 모델판, `/old/` 예전 화면, 주문관리)을 회사 서버에 붙여 브라우저로 확인. 오류 없음

## 설치 전에 정할 것

- 서버로 쓸 PC (24시간 켜 둘 PC)
- 거래처가 들어올 주소 (예: `pomall.회사도메인`) 와 도메인 관리자
- 인증 메일을 보낼 계정 (회사 메일 SMTP 또는 Gmail 앱 비밀번호)
