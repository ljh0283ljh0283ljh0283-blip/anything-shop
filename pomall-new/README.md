# SEKI POmall 발주 (견적 모델판)

기존 몰(`pomall/`)을 그대로 두고, 수정안(`pomall2/`)에서 시험한 **견적 모델 주문**을 넣은 새 사본입니다.
주소: `https://ljh0283ljh0283ljh0283-blip.github.io/anything-shop/pomall-new/`

- 기존 몰과 같은 실제 구글 시트·Apps Script(`settings.json`의 `orderUrl`)를 씁니다. 거래처, 비밀번호, 지난 발주가 그대로 보입니다.
- **거래처 관리**: 모델 단가 칸 대신 "주문모델 · 견적단가" 줄을 적습니다. "+ 주문모델 추가"로 줄을 늘리고 "빼기"로 지웁니다. 시트 `거래처` 탭의 `견적 모델` 칸에 저장됩니다.
- **주문하기**: 거래처가 로그인하면 "견적 모델 주문" 표(고객 주문모델, 확인, 수량, 희망납기일, 품목메모)에서 확인한 줄을 발주서에 담아 주문합니다. 견적단가에는 할인율을 적용하지 않고, 수량은 1EA 단위입니다. 품목 희망납기일은 시트 `발주` 탭의 `품목 희망납기일` 칸에, 견적 모델 품목은 `견적 모델` 칸에 Y로 남습니다.
- 모델을 직접 고르는 칸은 감춰 두었습니다(코드는 남아 있어 다시 보이게 할 수 있습니다).

## 쓰기 전에

이 폴더의 `pomall-script.gs`를 실제 Apps Script(SEKI POmall)에 붙여 넣고 **배포 관리 > 연필 > 새 버전 > 배포**를 누릅니다. 주소는 그대로이고, 기존 몰(`pomall/`)도 이 스크립트로 그대로 돌아갑니다. 기존 몰에서 거래처를 저장해도 견적 모델은 지워지지 않습니다.

나머지(관리 열쇠, 상태, 생산 소요일, 회사 서버 옮기기)는 `pomall/README.md`와 같습니다. 회사 서버(`pomall-server/`)도 견적 모델을 저장·주문할 수 있고, 이 화면을 쓰려면 `config.json`의 `siteDir`을 `../pomall-new`로 바꿉니다.
