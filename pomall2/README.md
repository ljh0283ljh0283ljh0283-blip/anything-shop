# SEKI POmall 수정안 (시험판)

지금 쓰는 `pomall/` 은 그대로 두고, 바꿔 보고 싶은 것을 먼저 고쳐 보는 사본입니다.

- 주소: https://ljh0283ljh0283ljh0283-blip.github.io/anything-shop/pomall2/
- 구글 시트에 연결되어 있지 않습니다(`settings.json` 의 `storage: local`). 여기서 넣은 주문과 거래처는 실제로 접수되지 않고 그 브라우저에만 저장됩니다.
- 시험해 보려면 맨 아래 **관리자** 를 누르고 아무 이름과 아무 열쇠(예: `test`)로 열어 거래처를 하나 만든 뒤, 그 코드와 비밀번호로 로그인하세요.
- 마음에 들면 바뀐 부분을 `pomall/` 에 옮겨 실제 버전에 반영합니다.

## 메일 인증번호까지 시험하려면 (수정안 전용 시험 시트)

브라우저 저장만으로는 메일을 보낼 수 없습니다. 실제 시트와 따로 쓰는 시험 시트를 하나 붙입니다.

1. 구글 드라이브에서 새 구글 시트를 만들고 이름을 `SEKI POmall 수정안` 으로 합니다.
2. 그 시트에서 **확장 프로그램 > Apps Script** 를 열고, 있던 내용을 지운 뒤 `pomall2/pomall-script.gs` 를 통째로 붙여 넣고 저장합니다.
3. **프로젝트 설정(톱니바퀴) > 스크립트 속성** 에 `ADMIN_KEY`, `SALES_KEY`, `VIEW_KEY` 를 넣습니다. 실제 열쇠와 다른 시험용 값을 쓰세요.
4. **배포 > 새 배포 > 유형: 웹 앱**, 실행: 나, 액세스: 모든 사용자 로 배포합니다. 권한을 물으면 허용합니다(메일 보내기 포함).
5. 나온 웹 앱 주소를 `pomall2/settings.json` 의 `orderUrl` 에 넣고 `storage` 를 `sheet` 로 바꿉니다.
6. 수정안 관리 화면에서 거래처를 만들 때 **메일** 칸에 받을 메일 주소를 적습니다.
