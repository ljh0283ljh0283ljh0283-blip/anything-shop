# SEKI POmall 발주

거래처가 우리 제품을 사양(모델, 와이어 길이, 동작온도)별로 골라 선주문 생산을 요청하는 발주 페이지입니다.
주소: `https://ljh0283ljh0283ljh0283-blip.github.io/anything-shop/pomall/`

- `index.html`, `style.css`, `app.js` 화면
- `products.json` 모델, 길이·온도 범위, 생산 기간 (모델 단가는 거래처마다 달라 여기 두지 않습니다)
- `settings.json` 오픈 여부(`open`), 주문 저장 방식(`storage`), 주문 받을 주소(`orderUrl`), 회사 이름(`company`)
- `pomall-script.gs` 거래처 로그인, 거래처별 단가, 발주를 구글 시트에 두는 Apps Script

## 화면

1. **주문하기**: 거래처 코드와 비밀번호로 로그인하면 그 거래처의 단가가 보입니다. 모델 선택, 와이어 길이·동작온도·수량 입력, 발주서에 담기, 발주 확정. 예상 출하일은 영업일로 계산합니다.
2. **주문 조회**: 로그인한 거래처의 발주 상태(접수 대기, 생산 확정, 생산 중, 출하 완료, 취소)를 보고 재주문합니다.
3. **관리**: 맨 아래 **관리자**를 누르고 이름과 팀 열쇠를 넣습니다. 열쇠마다 할 수 있는 일이 다릅니다.

   | 열쇠 (스크립트 속성) | 팀 | 발주 보기 | 상태 바꾸기 | 거래처 단가 |
   |---|---|---|---|---|
   | `ADMIN_KEY` | 관리자 | 예 | 아무 상태로나 (되돌리기, 취소된 발주 살리기 포함) | 예 |
   | `SALES_KEY` | 영업팀 | 예 | 앞으로만 (접수 대기 → 생산 확정 → 생산 중 → 출하 완료), 또는 취소 | 아니요 |
   | `VIEW_KEY` (선택) | 조회 전용 | 예 | 아니요 | 아니요 |

   - **발주 접수**: 모든 발주를 봅니다. 상태를 바꾸면 확인 창이 한 번 더 뜨고, 취소나 되돌리기는 사유를 적어야 합니다. 누가 언제 무엇을 왜 바꿨는지 시트의 `상태 기록` 탭에 남고 화면에도 보입니다.
   - **거래처 단가**: 거래처를 추가하고(코드, 비밀번호, 연락처) 모델마다 단가를 적습니다. 비워 둔 모델은 그 거래처에 "단가 문의"로 보이고 주문할 수 없습니다. 같은 내용이 구글 시트의 `거래처` 탭에도 있어 시트에서 직접 고쳐도 됩니다.

적은 단가가 와이어 길이, 온도, 수량과 상관없이 그대로 최종 단가입니다. 거래처에 **할인율(%)**을 적으면 그 거래처만 모든 모델 단가가 그만큼 깎입니다.

## 구글 시트 연결

1. 새 구글 시트를 만들고 (`발주`, `거래처` 탭은 처음 쓸 때 저절로 생깁니다) 확장 프로그램 > Apps Script에 `pomall-script.gs`를 붙여 넣습니다.
2. 프로젝트 설정 > 스크립트 속성에 `ADMIN_KEY`(관리자 열쇠), `SALES_KEY`(영업팀 열쇠), 필요하면 `VIEW_KEY`(조회 전용 열쇠)를 서로 다른 값으로 넣습니다. 누가 팀을 떠나면 그 열쇠 값만 바꾸면 됩니다.
3. 배포 > 새 배포 > 웹 앱, 액세스 권한 "모든 사용자"로 배포하고 나온 주소를 `settings.json`의 `orderUrl`에 넣습니다.
4. 준비가 되면 `open`을 `true`로 바꿉니다.

## 옮기기

- **다른 저장소나 호스팅으로**: `pomall` 폴더를 통째로 옮기면 됩니다. 모든 경로가 상대 경로라 어디서나 열립니다. 옮긴 뒤 Apps Script의 스크립트 속성 `PRODUCTS_URL`에 새 `products.json` 주소를 넣으세요.
- **다른 주문 저장소로**: `app.js`의 `STORAGES`에 `submit`, `lookup`, `list`, `setStatus` 네 가지를 하는 항목을 하나 더하고 `settings.json`의 `storage`를 그 이름으로 바꿉니다. 지금은 `sheet`(구글 시트)와 `local`(이 브라우저에만 저장, 화면 확인용)이 있습니다.
